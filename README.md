## Общее описание

Инструмент командной строки читает файл на учебном
конфигурационном языке и выводит эквивалентный YAML-документ
в стандартный вывод. Синтаксические ошибки сопровождаются
сообщениями с указанием позиции.

Входной язык поддерживает:
- однострочные комментарии `*> ...`;
- вещественные числа вида `[+-]?\d+\.\d+`;
- массивы `({ эл, эл, ... })`;
- имена `[a-z]+`;
- объявления `var имя значение;`;
- подстановку констант `|имя|`.

Для синтаксического разбора используется Lark.

## Функции и настройки

Модуль `src.parser`:
- `build_parser()` — возвращает объект Lark.
- `parse(text)` — разбирает исходный текст в AST.

Модуль `src.resolver`:
- `resolve(ast)` — подставляет `|имя|` значениями.

Модуль `src.emitter`:
- `to_yaml(data)` — превращает структуру в YAML-строку.

Модуль `src.cli`:
- `main()` — точка входа CLI.

## Сборка и тесты

Установка зависимостей:
pip install -r requirements.txt

Запуск транслятора:
run.bat examples/render.cfg

Запуск тестов:
pytest tests/

## Примеры использования

Входной файл `examples/render.cfg`:
*> настройки рендера
var width 1920.0;
var height 1080.0;
var center ({ |width|, |height| });

Команда: run.bat examples/render.cfg


Выход в stdout:
```yaml
width: 1920.0
height: 1080.0
center:
- 1920.0
- 1080.0
